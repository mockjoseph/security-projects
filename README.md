# Certificate Labs

## Project Overview
This project will be geared towards everything certificates, it should be a good overview of how to provision and manage different things as they are done in a normal company architecture

## Table of Contents


## Provisioning-Managing
In ./provisioning-managing you will see a project that is related to provisions and managing certificates. This was setup so that a VM (which acts as the application server) will be a user that is communicating with the PKI team (a personal computer), and all files are marked so that there is no ambiguity where scripts or pieces are run. Note that many organizations use tools to manage these items, but understanding how these things work at a lower level makes it much easier to zoom out and understand what is going on when using these tools and should increase intuition when coming across these tools.
