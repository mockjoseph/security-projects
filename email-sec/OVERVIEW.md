# Fully-Automated Email Phishing Analysis Tool

## Overview
I am building this project in hopes to learn more about email protocols and how emails are classified as phishing or legitamete. I have an understanding of things like DMARC, DKIM, and SPF, but I believe that you can not say you know how something works unless you can build it. Instead of "building the protocols from scratch" I want to build a tool that an actually be used, but requires an understanding of these protocols in order to make an assertation on a certain item.

## Goal
By the end of this project I hope to be able to pass an email into the runner and be able to get an assertation on whether or not it is a phishing email with a writeup at the end. I would like to run this entirely from the command line so that I do not require extra tools or outsourcing to be able to analyze an email that may come into my mailbox. I want to be able to be well versed in protocols such as DKIM, DMARC, and SPF with how they are setup, how they operate in practice, and ho things go wrong based on how people set up these protocols.
